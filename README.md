# My-Casino: Meta Quest 3 Slot Machine Starter

This repository now contains a Unity C# starter implementation for a VR slot machine experience with support for **8 unique video slots**, physical in-world XR controls with cabinet animation/haptics hooks, per-theme animation/audio plus dynamic lighting presets, synchronized payout-tier particles/emissive FX, and Quest hand-tracking gesture controls for spinning and slot selection.

See `Docs/META_QUEST_3_SLOT_MACHINE_SETUP.md` for setup and content authoring instructions.
See `Docs/ASSET_BIBLE_8_SLOT_THEMES.md` for full theme art direction, rarity, VFX language, and UI motifs.
